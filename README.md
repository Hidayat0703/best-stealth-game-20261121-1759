Night Vault — Shadow Heist: a top-down 2D canvas stealth game. Sneak past four patrolling guards with visible vision cones, hide behind crates and barrels, mind the lamplight, steal the Star Gem from the vault, and slip out the green EXIT unseen. Detection fills a meter with a chance to recover; an alarm sends every guard running for your last seen spot; running is fast and loud.

## Run it

```sh
node serve.ts
```
